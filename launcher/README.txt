========================================================================
Mighty Morphin Power Rangers: The Movie · PC Recomp - Windows x64
========================================================================

QUICK START:
1. Extract the contents of this ZIP to a folder on your drive.
2. Double-click "Play.bat" or run "MightyMorphinPowerRangersTheMovieSNESRecomp.exe".
3. On first run, select your original unheadered Super Nintendo ROM:
   "Mighty Morphin Power Rangers - The Movie (USA)" (.sfc or .smc).
   - The ROM must be an unpatched, unheadered USA dump (1,572,864 bytes).
4. The program validates its SHA-256 digest and securely imports a copy to:
   %LOCALAPPDATA%\PowerRangersMovieRecomp\
   Your original ROM file remains untouched.

DEFAULT CONTROLS:
- Keyboard:
  * Quick Save:           F1
  * Quick Load:           F2
  * Save Slots Menu:      F11
  * Toggle Original/HD:   F6
  * Video Settings:       F10
  * Toggle Fullscreen:    Alt + Enter
  * Open Launcher:        Ctrl + L

- Controller (PlayStation / Xbox):
  * Quick Save:           L2 / LT
  * Quick Load:           R2 / RT
  * Save Slots Menu:      Share + R1
  * Open Launcher:        Share + L3

USER DATA & PROGRESS:
Saves, configurations and HD packs are stored at:
%LOCALAPPDATA%\PowerRangersMovieRecomp\
