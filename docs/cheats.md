## 🛠️ Como Usar a Ferramenta de Cheats

A ferramenta [`tools/cheat_tool.py`](../tools/cheat_tool.py) permite inspecionar, decodificar e validar combinações de cheats:

### 1. Listar cheats disponíveis
```powershell
python tools/cheat_tool.py list config/power_rangers_the_movie_usa.cht
```

### 2. Decodificar um código individual
Converte o código Game Genie ou PAR para endereço físico e byte correspondente:
```powershell
python tools/cheat_tool.py decode DB6E-0D6D
# Saída: ROM address: 0x0081F2, value: 0x09
```

### 3. Validar uma combinação de cheats (sem conflitos)
```powershell
python tools/cheat_tool.py validate config/power_rangers_the_movie_usa.cht --select "0,1,2,15,18,25"
```
Se você selecionar cheats mutuamente exclusivos (por exemplo, começar com 9 vidas e começar com 5 vidas ao mesmo tempo), a ferramenta detectará e rejeitará o conflito de endereço antes do jogo iniciar.
